# M4 — Design

Apply the Claude Design system (`docs/design-brief/`, "Forge Design System.html")
to every screen. Light mode is the target; dark mode gets the sheet's dark
tokens so it doesn't regress, but is not polished this milestone.

## Decisions

1. **No ink cards.** The design's near-black "signature" panels (streak, resume
   banner, rest timer, est-1RM tile, session header) become light surfaces:
   `accentSoft` tint for the three that must stand out (streak hero, resume
   banner, rest timer), plain surface for the rest.
2. **Native chrome stays native.** Tab bar, nav bars, toolbar buttons, sheets and
   menus are system Liquid Glass. The rest timer moves into
   `tabViewBottomAccessory` — the iOS 26 idiom for a persistent floating bar.
3. **Warm-neutral tokens** from the style sheet live in one `ForgeColor` palette
   (asset-catalog colour sets, light + dark). Blue does three jobs and nothing
   else: `accent` graphics, `accentFill` buttons/ticks, `accentInk` text.
4. **Caps eyebrow labels** replace grouped-list section headers everywhere.
5. **Behaviour changes the design assumes** (kept small): sets are pre-created
   from the routine's target count and pre-filled from last time; the Workout
   tab shows a resume banner when a session is open; exercise cards in the active
   workout collapse to a summary row when they're not the one being worked.
6. **Dropped from the design:** the "+2.5" progression delta (no logic behind
   it) and long-press-to-reorder routines.

## Checkpoints

**A · Tokens + Home.** `ForgeColor`, type helpers (`tabular`, eyebrow), `Card`
and `SectionLabel` shared views. Home: streak hero with this-week strip,
consistency card, this-week stat tiles, 30-day bars with 30-slot domain, records
with PR chip and value.

**B · Workout tab.** Routine rows with Start pill and last-performed line,
"New routine" ghost button, resume banner when `hasActiveSession`. Routine detail
facts strip + Start pill in a glass bottom bar.

**C · Active workout + Session detail.** Progress header (exercise n of m,
sets done), collapsible exercise cards, "To beat" strip, set table with column
headers and a highlighted current set, pre-created sets, rest timer as
`tabViewBottomAccessory`. Session detail reuses the table with a "Completed"
facts header.

**D · Exercises + History.** Library rows and chips; exercise detail with hero
title, record tiles, metric/range controls, recent-sessions list. History with
month summaries and per-row volume bars.

**E · Settings, editors, empty states, haptics, Dynamic Type pass.**

Simulator pass and both test suites green before each commit; commit after review.
