# M6 — Workout polish

1. **Exercise notes** — `note` on `RoutineItem` and `WorkoutExercise`. Copied in at
   start; editing mid-workout writes back to the routine item, so it shows next
   time. Notes on exercises added mid-workout follow them into the routine when
   the post-Finish update is accepted. Also editable in the routine editor.
2. **Edit exercise mid-workout** — swipe → Edit opens the exercise editor
   (name, body part, bodyweight, unilateral ×2, default rest).
3. **Routine grid shows every exercise** with its set count, so a screenshot of
   the Workout tab is the whole programme.
4. **Workout screen is a `List`** — press-and-drag to reorder; swipe left for
   Edit / Remove, right for Note. The reorder sheet and long-press menu are gone.
